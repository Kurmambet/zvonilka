# ZVonilka

## Приложение звонков жи ес

### оно умеет:

- звонить напрямую
- звонить через реле (coturn на серваке)
- а еще приправлено вирусами для перчинки

### Что по технологиям?

- `на беке`: у нас вкусный fastapi + redis + postgres
- `на клиенте`: electron + vue + ts. webrtc
  - есть клиенты под windows и linux (планируется мобилка если подключение будет стабильным)
- `devops`: docker-compose + ansible, нащаника скоро cicd завезем
